<h1 align="center">小红书 · 顺序播放与循环重播</h1>

<p align="center">按页面顺序连续观看视频，也可以重复播放一条视频或整个队列。</p>

<p align="center">Chrome 扩展 · Manifest V3 · 原生 JavaScript · v1.0.6</p>

<p align="center">作者：<a href="https://github.com/DrRoyLiu">Roy Liu（@DrRoyLiu）</a></p>

## 功能

- **三种播放模式**：顺序播放、循环播放当前视频、队列循环播放，单选切换。
- **自动切换视频**：当前视频结束后，关闭详情并打开队列中的下一条。
- **自动重播**：优先点击播放器的重播控件；未恢复播放时，尝试从头播放。
- **视频卡片识别**：识别页面中带视频标记的笔记，过滤图文卡片并去重，兼容首页和作者主页笔记链接。
- **手动控制**：支持跳到下一个、刷新队列、停止接管和静音播放。
- **保存偏好**：记住播放模式和静音设置。
- **快捷入口**：无法连接当前页面时，显示“打开小红书”按钮。

## 安装

无需安装依赖或执行构建命令，可以直接加载源码文件夹。

1. 下载并解压项目，或将仓库克隆到本地。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
5. 打开 [小红书网页版](https://www.xiaohongshu.com/)，按网站要求完成登录。安装前已打开的页面需要刷新。
6. 点击 Chrome 工具栏中的扩展图标，打开播放面板。可以在扩展菜单中固定图标，方便使用。

> 下载 ZIP 后需要先解压；选择的是包含 `manifest.json` 的文件夹，而不是 ZIP 文件。

## 使用方法

### 连续播放页面视频

1. 进入小红书的视频列表页面，例如首页或作者主页。
2. 根据需要向下滚动，让页面加载更多视频卡片。
3. 打开扩展，选择 **顺序播放** 或 **队列循环播放**。
4. 点击 **开始播放**。扩展会扫描当前列表，从队列第一条开始播放。

### 重复播放一个视频

1. 在网页中打开想要重复观看的视频。
2. 在扩展中选择 **循环播放当前视频**。
3. 点击 **开始播放**，视频结束后会自动重播。

### 播放模式

| 模式 | 播放结束后的行为 |
| --- | --- |
| 顺序播放（默认） | 播放下一条，队列全部播放完毕后停止 |
| 循环播放当前视频 | 重播当前视频，直到切换模式或停止接管 |
| 队列循环播放 | 播放下一条，最后一条结束后回到第一条 |

三种模式每次只能选择一种。首次使用默认选择“顺序播放”，之后会记住你的选择。从旧版双开关配置升级时，首次也会采用“顺序播放”。

### 面板操作

| 控件 | 说明 |
| --- | --- |
| 开始播放 | 在列表页重新扫描并开始播放；已有视频详情打开时，接管当前视频 |
| 停止接管 | 停止自动重播和切换，恢复播放器原来的静音、原生循环设置；不强制暂停视频 |
| 下一个 | 跳过当前视频；队列循环模式下，在队尾会回到第一条 |
| 刷新队列 | 停止接管并重新扫描当前页面；扫描后需再次点击“开始播放” |
| 静音播放 | 以静音方式播放，浏览器阻止自动播放时可以尝试开启 |
| 打开小红书 | 在新标签页打开小红书，并关闭扩展弹窗；仅在无法连接当前页面时显示 |

## 队列规则与限制

- 队列只包含**当前已加载、仍在页面中且能识别出视频标记的卡片**。不会自动滚动加载作者的全部作品。
- 播放顺序按卡片上边缘从上到下排列；高度相同时从左到右排列。该顺序不一定等于发布时间顺序。
- 加载更多内容后，请返回列表刷新队列。页面移除或替换了队列中的卡片时，可能需要重新扫描。
- 单独打开的视频可以循环重播；顺序切换和队列循环需要页面中有可识别的视频列表。
- 刷新页面后需要重新点击“开始播放”。播放偏好会保留，队列和运行状态不会跨刷新保存。
- 扩展依赖小红书网页的卡片、播放器及关闭按钮结构。网站改版、不同页面布局或加载失败可能影响识别和切换。
- 后台标签页、设备休眠和浏览器自动播放策略可能影响播放或切换时机。

## 更新

1. 将新版文件解压到原扩展目录，替换旧文件。
2. 打开 `chrome://extensions`，点击此扩展的 **重新加载** 按钮。
3. 刷新已打开的小红书页面，再打开扩展面板。

只重新加载扩展而不刷新网页，旧页面中的脚本可能无法与新面板通信。

## 常见问题

### 页面有视频，但队列显示 0 个？

先确认页面已加载完成，再返回视频列表，向下滚动后点击“刷新队列”。图文笔记不会加入队列。如果某个页面仍无法识别，请提交该页面的公开链接及问题描述。

### 视频打开后没有自动播放？

请先确认视频能在网页中正常播放。可以手动点击一次播放，或开启“静音播放”后重新开始。

### 已经在小红书页面，为什么仍显示“打开小红书”？

这表示扩展面板没有连接到当前页面脚本。首次安装、更新扩展后，请刷新网页；同时确认当前网址为 `https://www.xiaohongshu.com/` 下的页面，并且扩展已启用。

### 为什么不会播放作者的全部视频？

扩展使用页面已加载的卡片建立队列，不会请求作者的完整作品列表，也不会自动无限滚动。可以先手动加载更多视频，再刷新队列。

### 点击“停止接管”后视频还在播放？

“停止接管”停止的是扩展的自动操作。需要暂停视频时，请使用网页播放器的暂停按钮。

## 权限与隐私

| 声明 | 用途 |
| --- | --- |
| `storage` | 在本地保存播放模式和静音偏好 |
| `activeTab` | 为用户主动打开扩展时对当前标签页的访问提供临时授权 |
| `https://www.xiaohongshu.com/*` 内容脚本匹配 | 在小红书网页中识别视频卡片、操作播放器并与面板通信 |

当前实现不包含统计分析、广告或数据上传逻辑，不读取或导出 Cookie、密码，也不调用小红书的非公开接口。队列保存在当前页面的内存中；视频加载和播放仍由小红书网页完成。
